---
title: "Extract Metadata"
description: "Extract metadata from translated models"
---

When you translate a model into the SVF format, the Model Derivative service saves information about the derivatives (metadata) in the manifest. When the source model is large, the manifest can become difficult to parse. As such, the Model Derivative API provides endpoints to specifically query metadata.

## Querying Viewables

`GET :urn/metadata` lets you extract information about the 3D Views and 2D sheets/views referenced in the manifest. These derivatives are the Viewables that you can typically display in a browser using the Forge Viewer SDK. See the tutorial on [Extract Metadata from a Source Model](/tutorials/tutorial-05/task4-metadata) to see how you can extract the names of Viewables and their metadata GUIDs (Global Unique Identifier).

<Note>
Source models from applications such as Autodesk Inventor and Fusion 360 produce only one Viewable per model. However, source models from applications such as Autodesk Revit can contain multiple Viewables.
</Note>

## Getting Object Hierarchy

Once you obtain the GUID of a Viewable, you can use `GET :urn/metadata/:guid` to obtain the object/component hierarchy of the model. In addition to the hierarchy, the list provides the `objectid` of each object. See the tutorial on [Extract Geometry from a Source File](/developers-guide/geometry-extraction) for a demonstration on how the object hierarchy and objectsids are used to uniquely identify geometry and thereafter extracted as OBJ files.

## Getting Object Properties

Using `GET :urn/metadata/:guid/properties` you can obtain a flat list of objects in that Viewable. It also returns the properties of each object. Using a query parameter, you can filter the results to provide the properties of one specific object.

## Related Endpoints

| Endpoint | Description |
|----------|-------------|
| `GET :urn/metadata` | Get list of Viewables in a model |
| `GET :urn/metadata/:guid` | Get object hierarchy for a Viewable |
| `GET :urn/metadata/:guid/properties` | Get properties of all objects |
| `POST :urn/metadata/:guid/properties:query` | Query specific properties |
