When an error occurs, APS typically provides additional information about what went wrong in the response body. The structure of the response body depends on whether the error was generated by the Data Management service or the Authentication service.

## Data Management Errors

Errors generated by the Data Management service typically return a 4** HTTP status code in the response header. The response body provides details of the error.

### Error Response Structure

| Attribute | Type | Description |
|-----------|------|-------------|
| `jsonapi` | object | An object containing information about the JSON:API specification this response is based on |
| `jsonapi.version` | string | The version of the JSON:API specification this response complies with |
| `errors` | array: object | An array of objects, where each element contains an object that represents an error |
| `errors.status` | string | The HTTP status code that was reported in the response header |
| `errors.code` | string | A code that identifies the error type |
| `errors.title` | string | A summary of the error, suitable for use as a title |
| `errors.detail` | string | A short, human readable explanation of the error |

### Example Error Response

```json
{
  "jsonapi": {
    "version": "1.0"
  },
  "errors": [
    {
      "status": "403",
      "code": "A360_ERROR",
      "title": "Unable to get hubs from A360.",
      "detail": "The client.id is not allowed two-legged A360 access."
    },
    {
      "status": "403",
      "code": "BIM360DM_ERROR",
      "title": "Unable to get hubs from BIM360DM US.",
      "detail": "You don't have permission to access this API"
    },
    {
      "status": "403",
      "code": "BIM360DM_ERROR",
      "title": "Unable to get hubs from BIM360DM EMEA.",
      "detail": "You don't have permission to access this API"
    }
  ]
}
```

## Common HTTP Status Codes

| Status Code | Message | Meaning |
|-------------|---------|---------|
| 200 | OK | Specified action was successfully completed |
| 400 | BAD REQUEST | The request was invalid. Check the response body for details |
| 401 | UNAUTHORIZED | The access token is invalid |
| 403 | FORBIDDEN | The request was refused. Check the response body for details |
| 415 | UNSUPPORTED MEDIA TYPE | The `Content-Type` header is missing or specifies an unsupported value |
| 429 | TOO MANY REQUESTS | The rate limit has been exceeded; wait some time before retrying |
| 500 | INTERNAL SERVER ERROR | An unexpected condition was encountered |
