## Common Uses

With the API, you can programmatically access manufacturing information and achieve a variety of cloud-based functionality:

- Navigate hub project folders, through files, all the way down to component properties
- Request only the data you need through tailored queries
- Retrieve the entire model hierarchy at once
- Access the Bill of Materials of a design
- Manage compliance by tracing the latest design data
- Subscribe to specific data events and be notified via Webhooks
