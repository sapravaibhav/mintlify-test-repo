This page contains a curated list of code samples that demonstrate how to use the Model Derivative API.

## Extract Revit Properties

<Card title="viewer-javascript-extract.spreadsheet" icon="github" href="https://github.com/Autodesk-Forge/viewer-javascript-extract.spreadsheet">
Uses the Model Derivative API to extract properties from a Revit file and generate an Excel Spreadsheet, where each sheet will contain one type/category of objects.
</Card>

**Technologies:** `Node.js`, `JavaScript ES6`, `Model Derivative V2`

## Translate a Model for Display in the Viewer (Node.js)

<Card title="learn.forge.viewmodels (Node.js)" icon="github" href="https://github.com/Autodesk-Forge/learn.forge.viewmodels/blob/nodejs/routes/modelderivative.js">
