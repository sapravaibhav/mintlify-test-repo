==============
Error Handling
==============

.. code-block:: shell

  Customize this page to contain information about the error handling information for your API.
  The authentication error handling and the HTTP status codes come from a reference to a text snippet in "Common Content".



When an error occurs, APS typically provides additional information about what went wrong in the response body. The structure of the response body depends on whether the error was generated by the Data Management service or the Authentication service. Check the Data Management Errors and Authentication Errors sections below to learn about the error response structure for each service.



**************************
Data Management Errors
**************************

Errors generated by the Data Management service typically return a 4** HTTP status code in the response header. The response body provides details of the error. The body structure of the error response for Data Management errors is as follows:

.. csv-table::
   :header: "Attribute", "Type", "Description"
   :widths: 10, 6, 30

   "jsonapi", "object",	"An object containing information about the JSON:API specification this response is based on"
   "jsonapi.version", "string", "The version of the JSON:API specification this response complies with."
   "errors", "array: object",	"An array of objects, where each element contains an object that represents an error."
   "errors.status", "string", "The HTTP status code that was reported in the response header."
   "errors.code", "string", "A code that identifies the error type."
   "errors.title", "string", "A summary of the error, suitable for use as a title."
   "errors.detail", "string", "A short, human readable explanation of the error."


Example
=======

..  code-block:: json

    {
      "jsonapi": {
        "version": "1.0"
      },
      "errors": [
        {
          "status": "403",
          "code": "A360_ERROR",
          "title": "Unable to get hubs from A360.",
          "detail": "The client.id is not allowed two-legged A360 access."
        },
        {
          "status": "403",
          "code": "BIM360DM_ERROR",
          "title": "Unable to get hubs from BIM360DM US.",
          "detail": "You don't have permission to access this API"
        },
        {
          "status": "403",
          "code": "BIM360DM_ERROR",
          "title": "Unable to get hubs from BIM360DM EMEA.",
          "detail": "You don't have permission to access this API"
        }
      ]
    }
